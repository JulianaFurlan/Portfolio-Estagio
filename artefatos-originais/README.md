# Artefatos originais do estágio

Esta pasta é a área de entrada dos artefatos reais do estágio. Coloque aqui os
arquivos originais (documentos, imagens, PDFs, diagramas etc.) dentro da
categoria correspondente:

- `Cronograma/` — planejamento das atividades do estágio.
- `Diagramas/` — diagramas de caso de uso, classes, fluxo, etc.
- `Documentos/` — documentação de requisitos e demais registros do projeto.
- `Telas/` — capturas das telas do sistema desenvolvido.
- `Termos/` — termos e formulários relacionados ao estágio.
- `Workflows/` — fluxos de trabalho e processos mapeados durante o estágio.

Se surgir uma categoria de artefato que não se encaixe nas pastas acima, crie
uma nova pasta com o nome apropriado — não force o arquivo em uma categoria
que não combina com ele.

**Atenção antes de adicionar arquivos aqui:**

- Documentos assinados, com nome/matrícula/assinatura de terceiros, dados
  reais de usuários, ou documentação interna sensível **não devem** ser
  publicados no site. Eles ainda podem ser colocados aqui para referência,
  mas serão sinalizados para confirmação antes de qualquer processamento.
- Esta pasta guarda os originais. As versões processadas/otimizadas que vão
  para o site ficam em `public/entregas/<categoria>/`, geradas a partir do
  que estiver aqui.

Esta pasta não é publicada como está — ela é a fonte usada para montar a seção
"Entregas" do portfólio.
